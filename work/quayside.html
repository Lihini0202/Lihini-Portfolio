Quayside: a developer tool explained in one scroll

A concept marketing site for a fictional open-source API gateway. I designed the website, sign-up flow, onboarding and launch email in Figma, and built the home page in code.

RoleDesign and front-end
ToolsFigma, HTML, CSS, JS
Timeline2026
LinksFigma prototype
The problem

Developer tools are hard to explain

API gateways sound technical and abstract. Most landing pages in this space list features without showing what the product actually does. I wanted a page where a developer understands the product in one scroll, and an engineering lead finds pricing and proof quickly.

Who it is for

Three kinds of visitor

  • Backend developers who want to see code and setup steps fast.
  • Engineering leads who care about reliability, security and cost.
  • Startup CTOs who decide in seconds whether it is worth a closer look.
What I did

From sketch to live page

  • Planned the site map and three user flows: sign-up, docs and talk to sales.
  • Designed desktop and mobile screens in Figma with reusable components.
  • Prototyped every flow so each button leads somewhere real.
  • Designed a launch email for desktop and mobile.
  • Built the home page in HTML, CSS and JavaScript and tested it with Lighthouse.

Key decisions

Why it looks the way it does

Show the product working, right in the hero

An animated "live traffic" panel shows requests passing or getting blocked at the gate. Visitors see what a gateway does before reading a word about it.

Real config, not marketing words

Developers trust code. A short YAML example shows how little setup is needed.

An FAQ written as real questions

Plain questions and answers help both visitors and AI search tools understand the product.
